# EarnPath｜六个结构单元初筛总览与迁移假设

> 日期：2026-08-17
> 性质：基于 VentureLab 已有研究的解释与迁移材料，不是新的事实源
> 边界：未新增检索；不排序最终赢家，不决定产品形态、滩头用户或价格

> 后续修正（2026-08-17）：本文是首轮结构总览，不是六张“一主体一卡”的深卡。`Side Hustle AI × GhostCoach`须在下一层拆开；“中国加盟体系”是邻近机制类别，不是单一竞品。文中的迁移卡只保留为结构假设，不等于可复制候选或产品定义。

## 90 秒版本

六个结构单元并没有在卖同一种东西：

| 对标 | 用户真正购买的核心 | 最值得借的结构 | 最不能假装拥有的资产 |
|---|---|---|---|
| Kosmo / Fiverr | 一次有外部调研动作的商业想法验证 | 固定范围、原始数据、明确砍留建议 | 平台流量、评价与信任 |
| Audos | AI、投放、人工和资本组成的创业工作室 | 尽快接触客户，用行为继续或淘汰 | 资本、广告能力、合同与项目组合 |
| 生财有术 | 长期环境、项目、关系和行动组织 | 固定周期行动场、成员复盘再供给 | 九年品牌、关系网络和内容密度 |
| Starter Story | 案例流量、会员、广告和训练营 | 内容获客后把用户送进固定交付 | SEO权重、采访库和创始人分发 |
| Side Hustle AI × GhostCoach | 低价路线生成或窄域持续建议 | 低摩擦、项目记忆、每次一个动作 | 尚未证明有独占数据或稳定采用 |
| 加盟体系 | 品牌、经营资源、培训和持续指导的完整路线包 | 把抽象建议变成可验收经营包 | 合法品牌、供应链、选址和持续支持能力 |

当前可继续比较的只是三段结构参考，不代表已经满足获客可迁移、成交可核或杨可进入：

1. **Kosmo 的固定项目与真实外部调研；**
2. **Audos 的“行动产生信息”；**
3. **Starter Story 的内容获客与案例资产。**

这三段可以组合，但尚未证明中国个人会购买，也没有形成杨的非人情可重复渠道。尤其是 Kosmo 的 Fiverr 分发、Starter Story 的长期内容分发和 Audos 的资本／投放体系，均不能因为交付结构可理解就假定能够复制。

## 一、本文怎样使用

本文件只承担轻筛与讲解，不能用材料篇幅代替主体证据。下一层按以下规则处理：

1. 六个命名主体分别为 Kosmo、Audos、生财有术、Starter Story、Side Hustle AI、GhostCoach；全部做轻筛。
2. 只有 2—3 个主体进入深卡。可核成交痕迹优先；无成交痕迹但具有独特高价或结构价值者可以例外，必须注明理由。
3. 只有官网、功能和营销文案的主体，不得称为“真实赚钱对标”，原则上只保留供给记录。
4. 所有未知字段必须显式写 `Ø`，尤其是客户数、获客成本、成交率、留存、人工投入和单位经济。
5. 获客机制可迁移，或存在具体替代获客路径，至少满足一项，才可进入主复制候选；否则只作结构参考。
6. 深卡必须回答：抄哪一段、拿不到什么、AI降低什么、第一版同构结构是什么、哪个 `Ø` 必须靠现实行为补。
7. 对标研究首先是创始人功课。它是否能成为付费产品、低价筛选层或交付过程，当前都是 `H`，不得由内部需要外推。

## 三、对标 1｜Kosmo Research / Fiverr

### 具体场景

一个人有商业点子，但不知道是否真的有人愿意付钱。他不是购买一份纯 AI 建议，而是在 Fiverr 上购买一个固定周期项目：研究者分析市场和竞品，接触潜在用户，测试支付意愿，并把原始数据与砍留建议交还给他。

| 字段 | 消化结果 |
|---|---|
| 最小售卖单位 | 单个商业想法的固定周期验证项目 |
| 谁付款／预算 | 个人创业者或副业者，从创业试错预算支付 |
| 价格证据 | `F-M/F-P`：页面基础档约 150 美元；已评价买家页面出现 100—400 美元实付区间。33 条评价能证明交易痕迹，不能证明完整订单数和利润 |
| 第一批客户来源 | `F-P/I`：Fiverr 平台搜索、卖家等级、评价与平台保障；站外来源 `Ø` |
| 人机分工 | 页面公开交付强调研究、问卷、访谈和分析；AI使用与自动化比例 `Ø` |
| 真正承载生存的资产 | `I`：平台分发、可核评价、固定交付和真实用户调研共同降低信任成本 |
| 可复制 | 固定边界；让外部行动进入交付；原始数据归客户；明确“不做／先做什么” |
| 不可直接复制 | Fiverr评价、平台流量、卖家历史订单和跨境信任 |
| 桌面天花板 | 利润、复购、获客来源占比、人工小时、中国迁移均无法由现有页面确认 |

### 对杨意味着什么

这是六项中最接近“对标迁移＋最低成本验证”的已付款形态，但买家购买的是**判断＋真实用户调研**，不能拿它证明“纯判断报告”值钱。

## 四、对标 2｜Audos

### 具体场景

一个普通创业者知道某类人的问题，却缺产品、投放和技术。Audos 不只给建议，而是用 AI 做访谈和原型，再配合广告、客户接触、导师、人工与分层资金，把方向送到市场。

| 字段 | 消化结果 |
|---|---|
| 最小售卖单位 | 不是一次咨询，而是一段从想法到客户信号的工作室关系 |
| 谁付款／预算 | 平台先承担部分工具、投放或资金，成功项目以收入分成等方式回收；现行统一合同 `Ø` |
| 价格证据 | `F-P/媒体披露`：不同时间出现 10%、15%分成和不同支持额度，属于不同层级，不得混成统一费率 |
| 第一批客户来源 | `F-P/媒体披露`：Instagram 广告与创始团队／媒体／活动；精确获客成本 `Ø` |
| 人机分工 | AI访谈、建站、代理和运营；人工导师、项目选择、客户互动、投放与资本继续承担关键责任 |
| 真正承载生存的资产 | `I`：AI只是入口，资本、广告能力、孵化方法、项目组合和人工选择更重 |
| 可复制 | 尽快接触潜在客户；用反馈和获客成本继续／停止；AI帮助生产第一版交付物 |
| 不可直接复制 | 资本、广告平台能力、Prehype方法、导师和投资网络、长期分成合同体系 |
| 桌面天花板 | 项目收入分布、淘汰率、人工分钟、回收期、退出与坏账 `Ø` |

### 对杨意味着什么

能借的是“行动产生信息”，不是照抄一个带资本和永久分成的创业工作室。

## 五、对标 3｜生财有术

### 具体场景

用户支付年度会费，不是为了拿到一条唯一答案，而是持续进入项目、内容、航海、同城活动和关系网络。即使某个项目没赚钱，环境、身份和新的机会仍可能构成续费理由。

| 字段 | 消化结果 |
|---|---|
| 最小售卖单位 | 年度会员资格；航海与活动嵌入会员体系 |
| 谁付款／预算 | 个人从知识付费、创业试错、社群与成长预算支付 |
| 价格证据 | `F-P`：当前页面挂牌 3365 元/年、72 小时退款；不能用成员数乘价格推收入 |
| 第一批客户来源 | `I/F-P`：创始人IP、成员口碑、推荐、活动和赚钱案例；渠道占比 `Ø` |
| 人机分工 | 核心内容、关系、教练、同城与成员复盘由人构成；AI进入新航海与工作流主题 |
| 真正承载生存的资产 | `I`：长期关系、持续内容、声誉、行动场和成员再供给 |
| 可复制 | 固定周期实战；用户复盘变内容；按项目形成临时同路人 |
| 不可直接复制 | 九年品牌、关系网络、内容存量、核心成员与中国搞钱语境 |
| 桌面天花板 | 当前有效付费、续费原因分布、现金收入、会员真实赚钱结果 `Ø` |

### 对杨意味着什么

生财证明“环境”与“一次判断”是两门不同生意。EarnPath如果只做低频判断，不能借用生财的续费逻辑计算 LTV。

## 六、对标 4｜Starter Story

### 具体场景

用户先从搜索引擎读真实创业案例，部分人购买会员、广告或训练营。案例既是内容，也是长期获客资产；当前训练营再把“看别人做”推进到固定时间内自己发布。

| 字段 | 消化结果 |
|---|---|
| 最小售卖单位 | 会员、广告／联盟曝光、或固定周期训练营 |
| 谁付款／预算 | 个人创业学习预算；广告主；部分用户尝试申请企业 L&D 报销 |
| 价格证据 | `F-P`：当前训练营页面存在约 395／495 美元等挂牌方案；实际成交、完成与利润 `Ø` |
| 第一批客户来源 | `F-P/I`：SEO案例、社交分享、YouTube与创始人品牌 |
| 人机分工 | 人负责采访、内容、教学、社群与办公时间；AI和开发工具降低发布门槛 |
| 真正承载生存的资产 | `I`：案例搜索流量、广告／联盟、会员和训练营组合，而非单一课程 |
| 可复制 | 公开案例获客；案例直接拆成项目动作；时间盒与交付物；内容导向服务 |
| 不可直接复制 | 多年SEO权重、采访库、Pat Walls分发和广告补贴 |
| 桌面天花板 | 当前收入结构、训练营完成率、首单率、退款与三个月存活 `Ø` |

### 对杨意味着什么

杨已有研究与内容生产能力，最可能借到的是“案例内容 → 信任 → 固定项目服务”，不是立即建一个大型案例会员库。

## 七、结构单元 5｜Side Hustle AI × GhostCoach（待拆为两张主体卡）

### 具体场景

Side Hustle AI 为普通个人生成路线、计划、模板和提醒；GhostCoach 则只服务已经经营订阅软件的人，保存项目状态并每次给一个动作。两者共同标定：纯生成和记忆正在变成低价功能，窄情境与持续使用也尚未自动形成壁垒。

| 字段 | 消化结果 |
|---|---|
| 最小售卖单位 | Side Hustle AI：低价月订阅；GhostCoach：窄域月订阅／早期终身方案 |
| 谁付款／预算 | 个人学习、软件与创业工具预算 |
| 价格证据 | `F-P`：约 9.99 美元/月；GhostCoach 79／99 美元/月及早期终身挂牌。真实付款、续费与利润未核 |
| 第一批客户来源 | App Store、细分SEO和创始人经验叙事；实际渠道效果 `Ø` |
| 人机分工 | AI承担大部分建议、计划、文案和记忆；真人关键复核和责任边界很弱或未公开 |
| 真正承载生存的资产 | `H/Ø`：可能是低摩擦、持续状态与窄框架；尚无独立采用证明 |
| 可复制 | 低摩擦输入；项目记忆；每次一个动作；提醒与结果回填 |
| 不可直接复制 | 当前没有已核不可复制资产；这本身就是风险 |
| 桌面天花板 | 下载、付款、留存、执行率、真实结果和相对通用模型增量 `Ø` |

### 对杨意味着什么

若 EarnPath 只输出画像、路线、90天计划和提醒，它面对的是每月约 10 美元产品与通用模型；高价必须来自外部行动、可信数据、责任或稀缺分发。

## 八、结构单元 6｜中国加盟体系（邻近机制，不是单一竞品）

### 具体场景

个人支付数万到十余万元，希望得到一条被验证过的经营路线。真实购买包通常包含品牌、经营资源、培训、设备、选址和持续指导，而不是单独购买“你适合做什么”的判断。

| 字段 | 消化结果 |
|---|---|
| 最小售卖单位 | 品牌／经营资源／培训／供应链／开店指导组成的经营包 |
| 谁付款／预算 | 想开店或创业的个人，从大额创业资本支付 |
| 价格证据 | `F-M`（Claude 单方已核法院原文，Codex 第二次原文复核待完成）：案例中出现 3 万、3.5 万、8.68 万、15 万、15.9 万等已付款；这些是争议案件，不代表健康加盟的平均成交价 |
| 第一批客户来源 | 典型案例涉及招商宣传和品牌招募；健康体系的渠道结构在本轮材料中 `Ø` |
| 人机分工 | 经营资源、选址、培训、供应链和持续支持高度依赖组织；AI不是样本核心 |
| 真正承载生存的资产 | `I/H`：合法品牌、标准化经营、供应链和持续支持可能承载价值；本轮争议样本不能证明健康单位经济 |
| 可复制 | 把抽象建议变成有明确边界、可验收的完整经营包；持续支持与冷静期设计 |
| 不可直接复制 | 品牌、供应链、两店一年等合规条件、选址与运营责任 |
| 桌面天花板 | 健康加盟体系的存活率、利润和用户选择理由并未由争议案件回答 |

### 对杨意味着什么

它证明中国个人会为“完整赚钱路线包”承担高额成本，但不能证明个人愿为判断本身付款。它同时提醒 EarnPath：越接近结果承诺、品牌授权和收入暗示，合规与声誉责任越重。

## 九、横向迁移判断（均降级为结构假设）

| 字段 | 初稿 |

### 结构假设 B｜Starter Story 的内容到服务

| 字段 | 初稿 |
|---|---|
| 复制骨架 | 用高质量对标案例吸引同情境人群，再出售固定周期的验证／执行服务 |
| 不复制资产 | 多年SEO、数千案例、创始人品牌、广告与联盟收入 |
| 杨的替代资源 | 已有案例研究流程、内容与交互产品制作能力、中文本地化判断 |

| 第一信号 | 非熟人因案例主动提出具体问题、提交真实资料或申请固定项目 |
| 停止线 | 内容只有浏览与赞同，持续不能带来同情境对话或可验收服务需求 |
| 通用模型缺口 | 真实案例采访、长期分发、可信筛选和后续交付责任 |
| 当前状态 | `H`：杨有生产能力，没有已核分发和转化 |

### Audos 作为过程原则，而非第三张公司迁移卡

只迁移一条：**尽快让候选接触真实客户，用行为继续或淘汰。**不迁移资本、永久分成和完整工作室叙事。
