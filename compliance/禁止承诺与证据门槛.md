# 禁止承诺与证据门槛

## 一、对外禁止表述

没有独立、可复核证据时，不得使用：

- 高确定性赚钱路线；
- 保证赚钱、保证回本、保证第一单；
- 最适合你的路线；
- 成功率、死亡率、平均窗口期；
- AI已经验证、市场已经验证；
- 唯一敢说真话、没有竞品、市场空白；
- 和你一样的人通常会赚或通常会失败；
- 陪跑到结果，除非合同精确定义结果和责任边界。

## 二、允许的最窄表达

- 帮你比较候选路线与当前资源的缺口；
- 明确哪些判断有证据、哪些没有；
- 把一项候选路线改写成低成本侦察动作；
- 预先限定时间、现金和停止条件；
- 不保证收入，但承诺按约定交付分析、实验设计和复盘；
- 数据不足时可以建议暂不投入。

## 三、结论证据门

| 对外结论 | 最低证据 |
|---|---|
| 有人愿意买 | 非人情预付，不是口头意愿 |
| 用户会执行 | 约定动作的真实完成记录 |
| 帮助获得市场信号 | 客户回复、询价、订单或明确拒绝 |
| 用户认为值得 | 不诱导的复购、转介绍或允许公开评价 |
| 可以规模化 | 多人可按同一流程交付，人工成本可覆盖 |
| AI创造额外价值 | 与通用模型或人工基线的可比测试 |
| 某类路线更适合某类人 | 足够多的可比成功与失败样本，含分母和反证 |

## 四、收费模式冲突登记

没有天然利益一致的模式：

- 固定诊断费：可能追求成交量、制造复杂报告或不愿枪毙太多路线；
- 订阅：可能延长依赖、优化留存而非缩短验证；
- 成功分成：可能偏好快速、可投放、易归因项目，拒绝困难用户；
- 推荐佣金：可能把推荐排序变成销售排序；
- 混合收费：可能叠加以上冲突。

每次实验必须披露收费方式，不接受与推荐项目之间未披露的佣金。

## 五、失败与退出

用户被建议停止一条路线，不等于用户失败。服务应说明：用了什么证据、仍不知道什么、损失是否在约定上限内、下一步是停止还是重新侦察。

用户可以在完整交付前取消；具体退款规则须在首次收费前由杨确认并写入报价，不得事后改变。

## 六、专业边界

本项目不替代法律、税务、投资、医疗、心理或持牌职业建议。涉及牌照、投资募集、劳动合同、个人征信、敏感健康或金融数据时停止常规交付，转介合格专业人士。
